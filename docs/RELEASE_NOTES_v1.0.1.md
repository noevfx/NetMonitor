## NetMonitor 1.0.1

### Corrigido
- O widget agora acompanha a barra de tarefas: some em tela cheia (navegador com F11, jogos, vídeos, preview do Premiere/After Effects, apresentações) e quando a barra se oculta automaticamente. Vale só para o monitor do widget.
- O assunto do e-mail de feedback (aba Sobre) usa a versão atual.

### Primeiro uso
O Windows pode exibir o aviso do **SmartScreen** por ser um app independente novo, ainda sem assinatura digital. Clique em **Mais informações** e depois em **Executar assim mesmo**.
